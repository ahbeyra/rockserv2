# Leveling Guide (Fuzzem)

This guide groups leveling areas by NPC level bands computed from NPC stat averages.
EXP values are estimated for a full kill on lightning, using current server multipliers.

Assumptions:
- Lightning EXP multiplier: 2.0x
- Full kill credit (killPct = 1.0)
- First kill bonus applied based on LIMIT (x4 for LIMIT 1, x1.8 otherwise)
- Non-hostile mobs reduce EXP by 30%

Legend:
- Level is computed as the average of NPC stats (matching player level behavior).
- EXP shows estimated Repeat / First Kill values.
